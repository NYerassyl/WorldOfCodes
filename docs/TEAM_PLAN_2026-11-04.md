## Remaining integration findings

1. `src/battle/socket.js` still validates sessions only during handshake. After logout/expiry, connected sockets can reach event handlers without another session lookup. Add protected-event revalidation and queue cleanup; test with real sockets.
2. The socket cooldown is per socket/per match. Reconnects or additional sockets can bypass it. Add per-user submission control and bounded judge scheduling shared with REST.
3. CORS alone does not reject WebSocket origins. Add explicit upgrade/origin admission, retaining the documented development and production origin allowlist.
4. `createBattleRouter` only accepts `{queue}` and calls submitBattleSolution without a supplied judge. Socket attachment supports injected judge. Add the same injection to REST, then share one bounded judge between transports.
5. REST queue pairing currently returns a match to the joining request; socket pairing emits battle:matched to both users. Agree on transport-independent notification or polling so a socket waiter is notified when its opponent joins through REST. Likewise REST settlement must reach socket subscribers, or the UI must poll/refetch authoritative state.
6. Socket.IO runtime dependency is absent from the service manifest. A passing fake-socket test does not prove installation/runtime compatibility.
7. After pairing finishes, the in-memory pairing guard clears. Verify a user already in an ACTIVE match cannot queue into another active match, including duplicate tabs. Per-user socket disconnect currently calls queue.leave even if another socket remains connected; define/test multi-tab behavior.
8. Live spectator access, beginner rating protection and algorithm-filtered matching are not implemented by the current participant-only API/classic Elo/random problem selection. Do not label these as working. Finish current week-one flow first; keep additional product behavior explicit.
9. PR #4 recorded three high npm-audit entries from one Prisma CLI deepmerge-ts dependency chain. Recheck on the final lockfile; do not perform an unreviewed Prisma major upgrade.
